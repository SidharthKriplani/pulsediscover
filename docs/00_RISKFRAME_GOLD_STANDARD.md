# 00 — RiskFrame Gold Standard (v4) — Controlling Rule

*The controlling standard for any BeastMax/T3/RiskFrame-gold claim. A project is **not** RiskFrame-gold until it passes this standard. A package/documentation checkpoint is **not** sufficient.*

---

## The chain (every gold project must trace it end-to-end)
**first-principles depth → product decision → implementation artifact → evidence → business consequence → interview defense.**

A project is RiskFrame-gold only if *every major claim* can be walked along this chain: the math/why (first principles) → the decision it informs (product) → the thing actually built (artifact) → the measured result (evidence) → the cost/benefit it changes (business) → the defensible spoken answer (interview).

## Hard rules
1. **Documentation alone cannot close technical gaps.** Memos do not substitute for builds. If an axis requires an artifact, only an artifact (or a real, scheduled evidence plan) closes it.
2. **No T3 claim without real evidence (plan or build).** "Advanced depth" may not be claimed on the basis of prose. Either the model/technique is built and measured, or it is an explicit documented deferral — never asserted as achieved.
3. **No number without the full stamp:** every quantitative claim carries **tag** (BUILT / SYNTHETIC / etc.), **N** (sample size), **CI / uncertainty**, **source** (artifact path), and **reproducibility status** (script + seed). A bare number is not evidence.
4. **No technique museums.** Every method present must serve a stated decision. Listing techniques for breadth is a defect, not depth. Each technique is classified Use-now / Baseline / V2 / T3 / Exclude with a reason.

## The 15 audit axes
1. Product thesis clarity
2. Market / JD relevance
3. Technique tournament depth
4. Deep Defense Kernel (per-technique first-principles defense)
5. Product Reasoning Kernel
6. Data realism / feature engineering
7. Synthetic realism audit
8. Evidence honesty
9. Evaluation validity
10. Decision economics
11. Industry-pattern awareness
12. Hairy failure modes
13. Achievement moments
14. Tradeoff density
15. Interview dominance

## Pass condition
RiskFrame-gold is achieved only when the audit scores **9+ on the binding axes AND real T3 evidence exists** (a built, measured competitive advanced model or a genuinely closed deep-defense/tournament layer). Until then the only permitted status labels are: *Package checkpoint complete*, *RiskFrame-gold incomplete*, *T3/model-depth open*, *Ready for next build gate*. The labels *BeastMax complete*, *T3 complete*, *gold-standard complete*, *fully maxed* are **prohibited** unless the pass condition holds.
